# 05: Log Out

**What to build:** From the Welcome Screen, a signed-in user can Log Out. This ends the Successful Login and returns them to a completely fresh login form: both fields empty, no Field Errors, no Rejected Login message, and keyboard focus on the email field. The previous email is not pre-filled.

**Blocked by:** 01 (Successful Login tracer bullet)

**Status:** ready-for-agent

- [ ] The Welcome Screen has a Log Out button.
- [ ] Activating Log Out shows the login form instead of the Welcome Screen.
- [ ] After Log Out both fields are empty and no Field Error or Rejected Login message is shown.
- [ ] After Log Out the email field has keyboard focus.
- [ ] Logging in again after Log Out works and shows the Welcome Screen with the new email.
- [ ] App-level tests cover each of the above.
